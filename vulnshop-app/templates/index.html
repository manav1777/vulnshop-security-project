Security Concepts

Explore common web application vulnerabilities and defensive concepts.

SQL Injection

Explore how unsafe database queries can allow attacker-controlled input to alter application behavior.

Cross-Site Scripting

Examine how untrusted user content can create client-side security risks when output is not handled safely.

Broken Access Control

Understand how missing authorization checks can expose resources belonging to other users.

Authentication

Explore authentication behavior, session handling, and account enumeration concepts.

Security Testing

Use the accompanying scanner to test application behavior and identify supported vulnerability scenarios.

Secure Remediation

Compare vulnerable behavior with safer implementation patterns to understand practical defenses.
